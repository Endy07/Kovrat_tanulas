Saját függvények

Eddig a Python függvényeit használtad: print, len, max. Most te magad írsz függvényt a def szóval. A függvény egy elnevezett programrész: bemenetet (paramétert) kap, dolgozik, és a return-nel visszaad egy eredményt. Egyszer megírod, és akárhányszor meghívhatod.

Python a böngésződben: írd át a hívások számait, és futtasd újra
Előtte: az 1–9. lecke (főleg a feltételek, a for és a listák). Ebben a leckében: def, a hívás, a paraméter, a return és a print különbsége, a None, alapértelmezett paraméter, helyi változó, függvény a függvényben, és lépésenkénti futtatás a függvénybe belépve (F11) a VS Code-ban. Ezzel a sorozat végére értél!

Gyakorlás

Hat feladattípus, három szinten. Az „Írd meg!” és a „Javítsd ki!” feladatnál elég a függvényt megírnod: a gép a program végén maga hívja meg több argumentummal, és megnézi, mit ad vissza (a kimenetben a @@ kezdetű sorok ezek a hívások). A „📝 Próbadolgozat” 12 vegyes feladat, a végén jegy.

Puska

def és hívásA def csak elkészíti a függvényt; lefutni a hívásra fog: terulet(3, 4).
return vagy print?A return visszaadja az eredményt, amivel tovább lehet számolni. A print csak kiírja; a függvény ilyenkor None-t ad vissza.
Annyi argumentum, ahány paraméterdef f(a, b) → f(3, 4). Kevesebbel vagy többel TypeError.
A return után végeA return azonnal kilép a függvényből; utána a sorok nem futnak le.
