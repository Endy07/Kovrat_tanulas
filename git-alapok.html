Puska

Három területmunkamappa → git add → staging → git commit → helyi repó → git push → GitHub
Egy napi munka
git pull
(dolgozol...)
git status
git add .
git commit -m "Mit csináltam"
git push
Soha ne commitoljjelszót, tokent, API-kulcsot (.env), nagy generált mappát (node_modules), személyes képeket nyilvános repóba. Ami már feltöltődött, azt a GitHub története megőrzi.
