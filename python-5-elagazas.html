Feltételek: if, elif, else

Eddig a program minden sort végrehajtott, fentről lefelé. Most megtanul dönteni: ha egy feltétel igaz, ezt csinálja, ha nem, azt. A feltétel értéke mindig True (igaz) vagy False (hamis), és a behúzás mutatja meg, mely sorok tartoznak a döntés alá.

Python a böngésződben: írj be más számot a „Bemenetek” mezőbe, és futtasd újra
Előtte: a 3. és a 4. lecke (int(input()), %). Ebben a leckében: összehasonlítás (== != < > <= >=), True és False, if, a kettőspont és a behúzás, else, elif, and, or, not, és a behúzás a VS Code-ban.
